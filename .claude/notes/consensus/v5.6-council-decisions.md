## Infrastructure — Nightly improvement routine

### Mandate
User delegated a daily self-improvement loop: scan Claude Code best-practices docs, identify deltas vs our `.claude/`, propose improvements, Council decides, implement on approval.

### Design

**Schedule**: daily 16:03 local time (user said "4:00 PM"; minute nudged off :00 per cron hygiene to reduce fleet-collision cost). Jitter up to 10% = arrives by ~16:18 worst case.

**Script**: `.claude/tools/nightly_improvement.py`. Stdlib only. Steps:
1. Fetch latest versions of 10 canonical Claude Code docs (code.claude.com/docs/en/*).
2. Diff against our cached synthesis (`.claude/notes/concepts/claude-code-best-practices-v5.4.md`).
3. For any new feature / pattern: generate a proposal artifact at `.claude/notes/concepts/proposals/nightly-<date>.md`.
4. Submit proposal to Council via protocol message (traces to `observability/traces.json`).
5. On Council approval: implement + log as `policy_amendment` in `memory/logs.json`; trigger `graphify --update`.
6. On Council rejection: log reason; keep proposal artifact for audit.
7. Emit summary to `memory/logs.json` regardless (`outcome: nightly_improvement_run`).

**Manual trigger**: `/nightly-review` slash command for on-demand run.

**Scope boundary**: Tier-3+ changes (constitution, policy, new agents) are logged as PROPOSED but NOT auto-applied — surfaced to user on next session for approval. Tier 1-2 changes (docs, rule additions, minor hook configs) are auto-applied.

**Kill switch**: `AGENTIC_OS_NIGHTLY_DISABLED=1` env var suppresses the routine.

### Verdict: **APPROVED and scheduled**.
