# Consensus: v5.4 Alignment with Anthropic Claude Code Best Practices

## Decision

Adopt the canonical Anthropic patterns documented at `code.claude.com/docs/en/*`.
Fill every gap where our architecture doesn't conflict. Preserve our architecture
(22 governance agents, Graphify knowledge layer, Karpathy invariant) — these
*exceed* the canonical minimum and should not be regressed.

## Council verdicts

### Architect
Our v5.3 architecture is **compatible** with every Anthropic pattern. None of
their docs forbid our governance layer; ours extends theirs. Adopt the canonical
load order, file conventions, and all 28 hook events as our expansion surface.

### Skeptic
Two risks: (1) adding 7+ new hooks bloats the hook surface and slows every tool
call. Mitigation: make new hooks cheap (< 100ms, soft by default). (2) Hook
event names must match Anthropic's casing exactly (`PostCompact` not
`postCompact`). Verified against docs.

### Pragmatist
Highest-ROI gaps: `.claude/rules/` (breaks monolithic CLAUDE.md into per-path
scopes), `autoMemoryEnabled: true` (free cross-session learning), and the
3 missing hooks that directly improve UX (Notification, PostCompact,
SessionStart compact-matcher). Ship these; defer the experimental 15.

### Critic
Don't migrate all 18 commands to skills. Commands still fully supported; skills
offer bundling but add directory overhead. Migrate selectively: only commands
that benefit from bundled supporting files. Keep single-purpose commands as
commands. Do create `.claude/skills/` scaffold with one reference skill so the
directory exists and is documented.

## Synthesis

4/4 agree on direction. Implementation scope:

### Ship in v5.4

1. **`.claude/rules/`** — 5 files with `paths:` frontmatter: `README.md`,
   `agents.md`, `hooks.md`, `notes.md`, `testing.md`.
2. **5 new hook scripts**:
   - `notification.py` → `Notification` event
   - `post_compact_reinject.py` → `PostCompact` event
   - `config_change_audit.py` → `ConfigChange` event
   - `session_end_summary.py` → `SessionEnd` event
   - `subagent_lifecycle.py` → `SubagentStart` + `SubagentStop`
3. **`settings.json` additions**: `permissions.allow/deny/defaultMode`,
   `autoMemoryEnabled: true`, `autoMemoryDirectory` pointing to `.claude/notes/self/`,
   registration of all 5 new hook scripts + `SessionStart(matcher: compact)` fork.
4. **Agent frontmatter hardening** on 5 governance agents (critic, evaluator,
   security, reflection, knowledge_validator): explicit `tools:` read-only lists,
   `model:` declaration, `memory: project`, `color:`, `maxTurns:` caps.
5. **Root files**: `.worktreeinclude`, `CLAUDE.local.md.example`.
6. **`.claude/skills/` scaffold** with one reference skill.
7. **CLAUDE.md v5.4** with new §36 documenting canonical alignment + link to this decision.
8. **Test check 40**: rules directory exists + hooks registered.

### Reject / Defer

- Full commands→skills migration (no benefit; commands still supported).
- Experimental hooks: `UserPromptSubmit`, `UserPromptExpansion`,
  `PermissionRequest/Denied`, `PostToolBatch`, `PostToolUseFailure`,
  `StopFailure`, `TeammateIdle`, `InstructionsLoaded`, `CwdChanged`,
  `FileChanged`, `WorktreeCreate/Remove`, `TaskCreated/Completed`,
  `Elicitation`/`ElicitationResult`. Add when a concrete use case surfaces.
- Agent Teams. Experimental; enable with `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`
  only when a specific fan-out use case emerges.
- Hook types `http`, `prompt`, `agent`. Our `command` type suffices.

## Reopen conditions

- Anthropic deprecates `.claude/commands/` → reopen migration.
- New hook event added → evaluate adoption.
- Agent Teams goes GA → enable + wire routing.
- A specific deferred hook proves necessary → add it on demand.
